# E46 M54B30 Visual Reference Photo Set
## Scope and reliability
This set is restricted as closely as the available indexed images allow to the M54B30 associated with the E46 330i/330Ci/330xi, or to isolated parts explicitly sold for those cars. The strongest whole-engine source is a complete 306S3/M54B30 removed from an E46 330i/330Ci; its listing identifies the donor as RHD, but does not state transmission or production date.[^1]

**Important limitation:** these are found reference images, not a controlled photogrammetry shoot. Almost none contain a ruler, known camera distance, orthographic projection, production date, or all requested metadata. Do not use apparent dimensions from perspective-heavy product photos as measured proportions.

## Highest-value missing shoot
A single controlled session with one complete RWD manual B30 on a stand and one complete automatic B30 in an E46 would close most gaps:

- Shoot six orthographic-style elevations from far back with a longer focal length; place two perpendicular metric scales in every frame.
- Record VIN-derived production month, LHD/RHD, gearbox, RWD/xi, engine serial and all visible cast/part numbers before disassembly.
- Keep camera height centered on the crank axis for front/rear and side elevations; add a bubble level and plumb line for the in-car crank-axis shot.
- Repeat top, intake-side and front views after removing, in order, beauty covers, coils, intake manifold, exhaust heat shields, gearbox/flywheel and oil pan.
- Photograph a color/scale card once per lighting setup and avoid phone ultrawide lenses.

The available evidence is useful for shape and component-placement reference, but it does **not** yet verify the 30-degree cant or support precision proportion extraction.
