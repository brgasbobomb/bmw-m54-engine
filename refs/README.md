# Reference photos

One folder per part, named like the part file in `src/parts/`.
Each folder has a `notes.md`. Read the notes first; open a photo only when the notes don't answer the question.

- `catalog/` — found reference set (40 photos). `catalog/photo-set.md` lists every photo with its section
  (whole engine, valve cover, oil pan, flywheel/starter, front drive, …). Use it as an index; open only the
  1–2 photos for the part being worked on.
